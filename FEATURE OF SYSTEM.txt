  FEATURE 13 — FINANCIAL HEALTH INDEX & SCORE
================================================================================

  ✔ Calculates a personal Financial Health Score from 0 to 100
  ✔ Displays a Grade: A+ (Excellent), A (Great), B (Good), C (Fair), D (Poor)
  ✔ Score is built from 4 sub-components:

       COMPONENT 1 — Savings Behavior (Savings Rate %)
          Measures what % of income is being saved each month

       COMPONENT 2 — Debt-to-Asset Ratio
          Measures total debts vs total assets (wallets + goals)
          Lower ratio = better score

       COMPONENT 3 — Budget Discipline
          Measures what % of budgets are on track vs exceeded

       COMPONENT 4 — Emergency Liquidity Reserve
          Measures if liquid balance can cover multiple months of expenses

  ✔ Score Evaluation Breakdown panel showing score per component
  ✔ Color-coded progress bars per component
  ✔ 30-Day Cash Flow Forecast:
       - Estimated daily spending (based on historical average)
       - Projected 30-day expense total
       - Current liquid balance (all accounts)
       - Projected end-of-month balance
  ✔ Deficit Risk Alert if projected balance goes negative
  ✔ Personalized actionable feedback messages based on score grade

       - Total saved in all active savings goals
  ✔ Liabilities include:
       - All active loan/debt remaining balances (loans you owe)
  ✔ Displays: Total Assets, Total Liabilities, Net Worth (difference)
  ✔ Assets Breakdown table: each account with its current balance
  ✔ Liabilities list: each debt with principal, repaid, remaining, due date
  ✔ Color-coded net worth (positive = green, negative = red)
  ✔ Shows "Zero Liabilities" success message if no active debts

================================================================================
                  PLANNED FEATURES — NOT YET IMPLEMENTED
================================================================================

  The following features are identified but not yet built in version 1.0.0.
  They are planned for the next development phase.

  [ ] Account Reconciliation
      Compare recorded account balance against actual bank statement balance
      and flag any discrepancies.

  [ ] Auto-Schedule Recurring Transactions
      Automatically run "generate_recurring" daily via Windows Task Scheduler
      so recurring income/expense records are created without manual command.

  [ ] Real Email Delivery (SMTP)
      Configure a real email provider (Gmail, Mailgun, etc.) so that password
      reset links are delivered to the user's inbox instead of the console.

  [ ] Swahili Chart Labels
      Chart.js dataset labels (Income, Expenses, Net Savings) currently display
      in English only. These will be translated using Django template tags.

  [ ] Swahili Offline/Online Status Messages
      "Online", "Offline", "Syncing data..." toast messages in offline.js
      are currently English only. Will be made translatable via data-* attributes.

  [ ] Month-over-Month Spending Comparison
      A chart comparing current month spending vs. previous month, highlighting
      categories where spending increased or decreased significantly.

  [ ] Budget Rollover
      Allow unused budget amounts to carry forward to the next period
      instead of resetting to zero each cycle.

  [ ] Transaction Duplicate Detection on Import
      When importing CSV files, detect and skip rows that appear to already
      exist in the database (same date, amount, and description).

  [ ] Two-Factor Authentication (2FA)
      Add an optional second login step using an authenticator app (TOTP)
      or SMS code for enhanced account security.

  [ ] Subscription Tracker
      A dedicated view that lists all recurring expenses that represent
      subscriptions (e.g. Netflix, internet, insurance) with a total
      monthly/annual cost summary.
